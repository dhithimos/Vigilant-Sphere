1. Endpoint Security Posture

Checks secure boot, TPM, BitLocker, Defender, antivirus, firewall, and UAC. Example finding: disk encryption disabled may expose sensitive data if stolen. Severity: HIGH.

2. Process Behavioral Analysis

Checks process tree, parent-child relationships, command lines, unsigned executables, and injection indicators. Detects encoded PowerShell, suspicious cmd children, rundll32/regsvr32 abuse. MITRE: T1059.001.

3. Persistence Mechanisms

Reviews Registry Run keys, Startup folder, Scheduled Tasks, services, WMI persistence, and browser extensions. Example: update_checker.exe in HKCU Run. Risk: HIGH.

4. Memory Threat Analysis

Looks for injected DLLs, process hollowing, reflective loading, memory-only malware, and unusual memory consumption. Example: svchost.exe code injection. Severity: CRITICAL.

5. Vulnerability Assessment

Reviews missing security updates, known CVEs, end-of-life software, and weak configurations. Example: outdated OpenSSL with CVEs. Severity: HIGH.

6. User & Identity Security

Checks inactive accounts, admin accounts, password policy, MFA status, and failed logins. Recommendation: reduce privileged accounts. Severity: MEDIUM.

7. File Integrity Monitoring

Monitors System32, Windows directory, critical executables, and configuration files. Example: modified svchost.exe. Severity: CRITICAL.

8. Malware & IOC Detection

Checks malicious hashes, malware signatures, YARA-style rules, and threat intelligence matches. Example: payload.exe classified as Trojan with 98% confidence.

9. Registry Security Audit

Reviews autorun keys, security policies, LSA protection, and Remote Registry. Example: Remote Registry enabled. Risk: MEDIUM.

10. USB & Removable Media Monitoring

Checks connected USB devices, USB history, and executable files from USB. Example: unknown storage device containing setup.exe. Severity: HIGH.

11. Service Security Analysis

Reviews running services, disabled security services, suspicious services, and auto-start services. Example: Remote Registry running. Severity: MEDIUM.

12. Application Whitelisting

Checks unauthorized software, pirated tools, and unknown executables. Example: crack_tool.exe unauthorized. Severity: HIGH.

13. Security Log Analysis

Checks failed logins, account lockouts, privilege escalation, and audit policy changes. Example: brute force activity after 342 failed logins. Severity: HIGH.

14. Threat Hunting Indicators

Checks encoded PowerShell, Base64 commands, LOLBins, and living-off-the-land activity. Example: certutil.exe LOLBin abuse. MITRE: T1105.

15. Compliance Validation

Checks CIS Controls, NIST Controls, ISO 27001 requirements, password policies, and patch levels. Example: CIS 87%, 4 failed controls.

16. Asset Criticality Assessment

Checks business importance, server role, data sensitivity, and exposure level. Example: Database Server criticality CRITICAL.

17. Security Score Engine

Formula: Endpoint Security + Vulnerabilities + Threat Detections + Compliance + Patch Status. Output includes Security Score and Risk Level.

18. MITRE ATT&CK Mapping

Maps detections to T1059 Command Execution, T1547 Persistence, T1055 Process Injection, T1021 Remote Services, and T1071 Command & Control.

19. Automated Remediation Suggestions

Enable Firewall, apply updates, remove unauthorized software, disable Remote Registry, rotate administrator passwords, and quarantine suspicious files.

20. Executive Summary

SOC-style summary of score, risk, critical/high/medium findings, patch gaps, suspicious processes, persistence, malware detections, compliance, and recommended action.
