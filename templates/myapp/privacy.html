Privacy and local data handling

This page describes application behavior, not a legal compliance certification.

Accounts and sessions

Account identifiers, password hashes and session records are stored in the configured database. Browser session and CSRF cookies support authentication. The chosen Day/Night theme is stored in browser localStorage.

Scans and evidence

Targets, findings, static strings, hashes, timestamps and available host metadata can be retained in scan history. Uploaded scan samples are analyzed in memory or bounded temporary storage for optional static tools and are not executed. Findings may contain sensitive content; review evidence before sharing reports.

Incident attachments

Evidence attachments are stored in the database and downloaded only through authorized owner/responder routes. They are not served as public media. Database backups also contain attachments.

Password tools

Password analysis and generation run in the browser. Their input is not sent to Django or stored in theme preferences. If an optional k-anonymity password check is enabled, only a hash prefix is sent directly to that service.

External requests

URL/DNS/TLS analysis contacts the requested target or resolver. Configured reputation providers may receive the indicator being checked. Keys remain in server environment configuration. Missing providers are shown as unavailable. The Local Security Assistant uses local content and stored account evidence, with no external language-model service.

Contact and suggestions

Submitted names, email addresses, categories and messages are stored locally for review. Do not submit secrets.

Logs and retention

Application audit records track actions. Raw process command arguments are not retained by the behavioral scanner. Records remain until the operator removes them; there is no automatic global data-retention policy. IOC expiry deactivates stale indicators without deleting them. Local administrators can manage shared application data; use this local deployment only with trusted accounts.
