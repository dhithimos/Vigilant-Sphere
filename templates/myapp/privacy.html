Privacy Policy

This project stores registered users, profile details, contact messages, scan ratings, activity logs, and scan results in the local SQLite database. Scan results may include local paths, open ports, IP addresses, user-agent device text, and security recommendations.

Reports are designed for local SOC-style learning and review. Do not publish reports unless you have removed private file paths, usernames, IP addresses, and any sensitive evidence.

Superusers can view admin analytics and download user detail CSV files for the local application only.
