Threat Detection

Runs process hunting, startup persistence review, suspicious file detection, MITRE ATT&CK hints, risk scoring, and remediation advice.

Tier 1: Endpoint Detection & Response (EDR)

Inputs: running processes, parent-child process relationships, command line arguments, PowerShell activity, scheduled tasks, services, DLL loading, registry changes, and startup entries.

Example: Suspicious PowerShell Execution | HIGH | T1059.001 | Confidence 94% | Action: Isolate Endpoint.

Tier 2: Network Detection & Response (NDR)

Inputs: active connections, DNS queries, HTTP requests, TLS certificates, ports, network flows, and packet metadata.

Detects: beaconing, port scanning, lateral movement, C2 communication, data exfiltration, and DNS tunneling.

Tier 3: File Threat Analysis

Checks downloads, USB files, attachments, hashes, metadata, entropy indicators, packed executables, unsigned binaries, and YARA-style matches.

Tier 4: User Behavior Analytics (UBA)

Reviews login times, user activity, admin actions, failed logins, privilege escalation signals, impossible travel, takeover, brute force, and insider risk.

Tier 5: Threat Intelligence Integration

Accepts IPs, domains, URLs, and hashes. Sources can include AbuseIPDB, AlienVault OTX, MISP, VirusTotal, and CISA advisories when API keys are configured.

Tier 6: MITRE ATT&CK Mapping

Every detection maps to ATT&CK where possible, such as T1055 Process Injection, T1204 User Execution, and T1059 PowerShell.

Tier 7: Risk Engine

Threat Score = Severity + Behavior + Reputation + Asset Criticality. Mapping: 0-20 LOW, 21-40 MEDIUM, 41-70 HIGH, 71-100 CRITICAL.

Tier 8: Automated Response (SOAR)

Suggested actions: kill process, block IP, disable user, quarantine file, disconnect endpoint, create ticket, and send alert. Destructive actions require analyst approval.

Tier 9: SOC Dashboard

Shows active threats, critical alerts, high alerts, suspicious processes, malicious IPs, latest detection, MITRE technique, confidence, and response status.

Tier 10: Executive Security Metrics

Security posture score, MTTD, MTTR, open incidents, compliance status, and asset coverage.
